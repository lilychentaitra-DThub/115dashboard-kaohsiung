### 素材處理

- **報名 QR**：原始檔 1890×1890，縮到 900×900 存檔。縮圖後實測仍可正確解碼，
  指向 `https://forms.cloud.microsoft/r/JvDJNXkVc7`（**高雄辦事處專屬表單**）。
  16 頁版用的通用表單 QR（`8ngfPR3vkc`）已移到 `assets/_unused/`，兩者是不同入口，不要混用。
- **兩枚 logo**：原始檔四周都有大量透明留白（TAITRA 原檔 4334×4334，實際內容只占中間一條），
  已依 alpha 通道裁到內容邊界，再統一正規化成 120px 高。CSS 用 `height` 控制、`width:auto`，
  兩枚 logo 的視覺重量才會一致。
- 兩枚 logo 都是**深色去背**檔：現在放在淺色紙面上，直接放即可（`.logobar.plain`）。
  若日後要移到深藍頁，改用不加 `.plain` 的版本墊白底，否則深色 logo 會整個吃進背景裡。

## 技術說明

- 單一 HTML 檔，無外部相依套件，離線可用（字型 fallback 到系統的微軟正黑體／PingFang TC）
- 橫向 scroll-snap 換頁，`prefers-reduced-motion` 下自動關閉所有動態
- 第 06 頁的趨勢折線圖是 inline SVG，不是圖檔
- 圖檔一律用 ASCII 檔名，避免中文路徑的編碼問題
- 已驗證 1024×768、1280×720、1366×768、1600×900、1920×1080 五種投影尺寸下 9 頁均不溢出

### 失效防護（改版時務必保留）

- 動畫一律 `animation-fill-mode: backwards` 而非 `both`。backwards 只在「延遲期間」套用起始狀態，
  結束後回到元素本來可見的樣子；若用 `both`，動畫被瀏覽器節流或中斷時內容會**永遠停在 opacity:0**，整頁空白。
- 螢光筆用 `background-image` 圖層而非 `::before` 疊層，靜止狀態就是「已畫滿」，動畫沒跑也看得到。
- 印章的 `visibility` 由 `.stamped` class 直接控制，不靠動畫；動畫沒跑印章仍然蓋得出來。
- 數字滾動另有兩道保險：分頁不可見時（`document.hidden`）直接顯示正確值不跑動畫；
  切換分頁時把滾動中的數字補成最終值，避免畫面停在滾動途中的假價格。
- `.seal.seal-pin` 用雙 class 提高權重，否則會被後面動畫區塊的 `.seal{position:relative}` 蓋掉（同權重、後者勝）。
